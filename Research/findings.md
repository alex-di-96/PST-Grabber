# Исследование: Конвертация Outlook PST в Thunderbird

## 1. Основные инструменты (Open Source)

### libpst (readpst) — Стандарт индустрии
*   **Описание:** Консольная утилита (написана на C), самая надежная для массовой конвертации.
*   **Плюсы:** Высокая скорость, малый расход памяти (потоковая обработка), поддержка ANSI и Unicode PST.
*   **Ключевые флаги для Thunderbird:**
    *   `-u`: Принудительный вывод в UTF-8 (критично для кириллицы).
    *   `-M`: Формат MBOX (родной для Thunderbird).
    *   `-r`: Рекурсивный обход папок с сохранением структуры.
    *   `-o <dir>`: Выходная директория.

### libratom (Python)
*   **Описание:** Современная библиотека для работы с PST, построенная на базе `libpff`.
*   **Плюсы:** Удобный Python API, хорошо подходит для фильтрации или поиска перед конвертацией.
*   **Минусы:** Может быть медленнее `readpst` на огромных файлах.

### pypff (Python)
*   **Описание:** Низкоуровневые биндинги к `libpff`.
*   **Минусы:** Проблемы с памятью на больших файлах (>10-20 ГБ), сложность API.

## 2. Подводные камни и решения

### А. Кодировка (Кириллица)
*   **Проблема:** Старые PST (Outlook 2002 и старше) используют ANSI. При конвертации русские буквы превращаются в "кракозябры" (mojibake).
*   **Решение:** 
    1. Использовать `readpst -u` для принудительного UTF-8.
    2. Если не помогло, в Thunderbird нажать правой кнопкой на папку -> Свойства -> Кодировка -> Выбрать Cyrillic (Windows-1251) или UTF-8.

### Б. Вложенные изображения (Embedded Images)
*   **Проблема:** Изображения внутри письма (inline) часто пропадают или отображаются как обычные вложения. Это происходит из-за потери ссылок `cid:`.
*   **Решение:** Использовать флаг `-M` в `readpst`. Он формирует правильную MIME-структуру `multipart/related`, которую понимает Thunderbird.

### В. winmail.dat (TNEF)
*   **Проблема:** Outlook часто упаковывает вложения в проприетарный формат TNEF, если письмо было в Rich Text Format (RTF).
*   **Решение:**
    1. Использовать плагин для Thunderbird: **LookOut (fix version)**.
    2. Или утилиту `tnef` в Linux для предварительной распаковки.

### Г. Огромные файлы и память
*   **Проблема:** Python-библиотеки часто пытаются загрузить структуру папок в RAM, что ведет к падениям на файлах 50ГБ+.
*   **Решение:** Использовать `readpst`, так как он работает последовательно и не требует много памяти.

### Д. Импорт структуры папок
*   **Проблема:** Thunderbird не всегда корректно видит вложенные папки MBOX.
*   **Решение:** 
    1. Соблюдать иерархию `.sbd` директорий (например, для папки `Work` с подпапкой `Project` нужен файл `Work` и папка `Work.sbd`, внутри которой лежит файл `Project`).
    2. Использовать плагин **ImportExportTools NG** для автоматизации импорта.

## 3. Автоматизация (Implementation Plan)

1.  **Поиск PST:** Скрипт сканирует папку `Samples`.
2.  **Конвертация:** Вызов `readpst -u -r -M -o ./Output <filename>.pst`.
3.  **Пост-обработка:**
    *   Переименование файлов (удаление расширения `.mbox`, если оно есть).
    *   Создание структуры `.sbd` для вложенных папок.
4.  **Инъекция:** Копирование результата в `~/.thunderbird/<profile>/Mail/Local Folders/`.
